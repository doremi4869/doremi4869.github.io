# Jinyang Website

Static personal website for GitHub Pages.

## Publish With GitHub Pages

1. Create a public GitHub repository named `k-kuroba.github.io` for a user site, or another repository name for a project site.
2. Push this folder to the repository's `main` branch.
3. In the repository, go to Settings -> Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch `main` and folder `/ (root)`, then save.

For a user site named `k-kuroba.github.io`, the site URL will be:

```text
https://k-kuroba.github.io/
```

For a project site, the URL will usually be:

```text
https://k-kuroba.github.io/repository-name/
```
